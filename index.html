01 // About Me

Information Technology student, 22, based in Alexandria and studying at Borg El Arab Technological University, specializing in the networking track — CCNA, Network+, subnetting, and Linux fundamentals. That's my core specialization and where my formal study is focused.

Alongside that, I have a genuine passion for full-stack web development. I build complete products — React and Next.js on the front end, Node and NestJS APIs on the back end, real databases doing real work — end to end, from the first component to a live deployment.

Everything below started as something specific, not an exercise: a graduation project that models drug interactions in 3D, a QR generator I still push updates to on weekends, a produce delivery platform I'm building for an actual store here in Alexandria. Each one shipped because a real problem needed solving, not because a tutorial said to build it. And knowing how systems get broken into, from the networking side, changes how I build them in the first place.
